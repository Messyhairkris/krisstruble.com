# Specimens

Gaussian-splat scans.

## Publish

1. Create an empty GitHub repository and push everything in this folder to it.
2. **Settings → Pages → Deploy from a branch → `main` / `root`.**
3. The gallery is live at `https://<you>.github.io/<repo>/`.

`.nojekyll` is included so GitHub serves the `js/` folder as-is.

## What's here

| Path | |
|---|---|
| `index.html` | redirect to the gallery |
| `viewer/` | the gallery page |
| `js/` | renderer, camera tours, hotspots |
| `data/portfolio.json` | every specimen's title, docs, tour and markers |
| `assets/` | the `.spz` splat files |
