Chapter III · Education & Program Design

Classes as a System

I relaunched Paxton Gate’s dormant workshop program, eventually running 46 workshops a year across insect spreading and taxidermy. A two-hour class looks simple from the student’s seat. There was a lot of work behind making it feel that way.

  • Learning design
  • Documentation
  • Program building
46workshops a year, across insect spreading and taxidermy
5stages from sign-up to follow-up, each one designed
1document set per species taught

The class, from sign-up to follow-up

  1. RegistrationA certificate-style confirmation with the date, place and policies
  2. Two weeks outA prep email from me, so everyone arrives ready
  3. PrepFoam, vellum and grid paper cut; every material checked and stocked
  4. The classA written curriculum and a full document set for the species
  5. AfterA follow-up email to close the loop
