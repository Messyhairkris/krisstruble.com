Why I built a tool

Most people don’t know a phone can do this. The hard part is the step between the phone and a web page: raw captures are 10–33 MB each, full of floating specks and glowing haze, and every fix meant opening another program.

So I built Splat Portfolio with Claude Code: one browser app that cleans a scan, shrinks it for the web, sets a camera tour, adds notes, and exports a site ready for GitHub Pages. It’s the viewer you’re using above.

Where the megabytes are

Along the way I found out where the megabytes actually are: 73% of a raw file is color detail that changes with viewing angle. Deleting floaters barely helps; re-encoding does. I wrote that finding into the tool, so it explains itself to the next person.
